# LinkedIn Hackathon Challenge – Mutual Connections (Java)

## Overview
Identify the intersection of two professional networks to find common links.

## Objective
Use `HashSet` and its built-in `retainAll` method to solve a common graph problem efficiently.

## Analysis
- **Time Complexity**: O(N + M) where N and M are the sizes of the networks.
- **Concepts**: Set intersection, Collection Framework.
