# Spotify Hackathon Challenge – Music Queue Manager (Vue)

## Overview

This repository contains a Vue 3 solution inspired by Spotify's play queue logic. The goal is to manage a reactive list of tracks, allowing users to prioritize songs ("Play Next") or remove them from the upcoming list.

---

## Problem Description

Manage a list of tracks where:
- The first element is always "Now Playing".
- Other elements are in the "Queue".
- Actions must modify the underlying array reactively.

---

## Objective

Practice Vue's Composition API (`ref`, `computed`) and efficient array manipulation using ES6+ methods.
