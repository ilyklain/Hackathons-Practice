# Instagram Hackathon Challenge – Safety Filter (Python)

## Overview
Detect prohibited hashtags even when users try to bypass filters using numbers instead of letters (leetspeak).

## Objective
Normalize strings and translate common character substitutions to catch variations of forbidden words.

## Analysis
- **Time Complexity**: O(N * L) where N is number of tags and L is average length.
- **Concepts**: String normalization, Dictionary mapping.
