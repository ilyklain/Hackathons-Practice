# Google Photos Hackathon Challenge – Yearly Organizer (Kotlin)

## Overview
Group a large collection of photos into chronological folders based on their capture date metadata.

## Objective
Use Kotlin's high-level `groupBy` function to transform a flat list into a year-indexed map.

## Analysis
- **Time Complexity**: O(N) where N is the number of photos.
- **Concepts**: Data classes, Collection grouping.
