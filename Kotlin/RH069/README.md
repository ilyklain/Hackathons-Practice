# Robinhood Hackathon Challenge – Limit Orders (Kotlin)

## Overview
Detect when a financial instrument reaches a specific price point to automate trades or notifications.

## Objective
Implement dual-mode threshold logic ("BUY" vs "SELL") using Kotlin's expressive `when` expression.

## Analysis
- **Time Complexity**: O(1)
- **Concepts**: Conditional expressions, Financial logic.
