# Evernote Hackathon Challenge – Read Time (Kotlin)

## Overview
Provide users with an instant estimate of how long it will take to read a specific note.

## Objective
Count words using Regex and apply a human-centric reading speed constant to calculate duration.

## Analysis
- **Time Complexity**: O(N) where N is text length.
- **Concepts**: Regex splitting, Math ceilings.
