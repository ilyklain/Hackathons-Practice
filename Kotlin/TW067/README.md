# Twitch Hackathon Challenge – Emote Detector (Kotlin)

## Overview
Identify and count specific community emotes within a raw chat message for rendering optimization.

## Objective
Tokenize a string and use containment checks to quantify the presence of predefined keywords.

## Analysis
- **Time Complexity**: O(W) where W is the number of words in the message.
- **Concepts**: String tokenization, Collection filtering.
