# Twitch Hackathon Challenge – Milestone Tracker (JS)

## Overview
Twitch triggers festive alerts when streamers cross viewer milestones (e.g., every 1k viewers).

## Objective
Build a stateful tracker that only triggers an alert when a *new* threshold is crossed.

## Analysis
- **Time Complexity**: O(1)
- **Concepts**: Stateful logic, Threshold detection.
