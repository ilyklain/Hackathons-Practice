# Airbnb Hackathon Challenge – Stay Picker Logic (React)

## Overview

This repository contains a React solution focusing on the core logic of Airbnb's date selection flow. The goal is to manage the complex state transitions of choosing a check-in and check-out date while calculating real-time pricing.

---

## Problem Description

Implement a Date Range selection mechanism:
- **Rule 1**: First click sets Check-in.
- **Rule 2**: Second click (if after Check-in) sets Check-out.
- **Rule 3**: Subsequent clicks reset and start a new range.
- **Calculation**: Dynamically calculate the total cost based on the number of nights.

---

## Objective

Demonstrate proficiency with React `useState`, `useMemo`, and handling Date objects in a reactive environment.
