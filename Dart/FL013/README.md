# Google / Flutter Hackathon Challenge – Input Throttler (Dart)

## Overview

This repository contains a Dart solution to a Flutter-style hackathon challenge focused on UI performance and reactive programming. The goal is to prevent excessive API calls by throttling user input events.

---

## Problem Description

Implement a time-based filter that only permits an action if a minimum cooldown period (`throttleTime`) has passed since the last successful action.

---

## Objective

Simulate real-time event handling using Dart's object-oriented approach.

---
