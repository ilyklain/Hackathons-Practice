# Mailchimp Hackathon Challenge – Audience Validator (PHP)

## Overview
Clean up marketing lists by removing entries with missing or malformatted data before starting a campaign.

## Objective
Apply `array_filter` with a custom closure to enforce data integrity across complex nested arrays.

## Analysis
- **Time Complexity**: O(N) where N is the number of contacts.
- **Concepts**: array_filter, Closures, Data validation.
