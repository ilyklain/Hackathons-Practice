# Wikipedia Hackathon Challenge – Keyword Highlighter (PHP)

## Overview
Engineers at Wikipedia need to process large bodies of text to help users identify relevant information quickly through visual cues.

## Objective
Implement a case-insensitive search that counts occurrences and modifies the text to highlight matches.

## Analysis
- **Time Complexity**: O(T) where T is text length.
- **Concepts**: Regular expressions, Case-insensitive matching.
