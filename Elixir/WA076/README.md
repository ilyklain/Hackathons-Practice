# WhatsApp Hackathon Challenge – FIFO Queue (Elixir)

## Overview
Model the sequential delivery of chat messages using functional recursion to ensure order integrity.

## Objective
Master tail recursion in Elixir to iterate through a payload list while maintaining a sequence counter.

## Analysis
- **Time Complexity**: O(N) where N is the number of messages.
- **Concepts**: Tail recursion, Pattern matching on lists.
