# Twitch Hackathon Challenge – Command Counter (Elixir)

## Overview
Monitor live chat interactions by identifying and quantifying automated bot commands in real-time.

## Objective
Leverage Elixir's `Enum` module to filter and count strings based on prefix patterns.

## Analysis
- **Time Complexity**: O(N) where N is the number of messages.
- **Concepts**: Enum module, String prefix checking.
