# Linear Hackathon Challenge – Kanban State Transitions (Svelte)

## Overview

This repository contains a Svelte solution focusing on the high-speed state transitions characteristic of the Linear issue tracker. The challenge is to manage task statuses across columns using Svelte's reactive declarations.

---

## Problem Description

Implement a mini-Kanban board where:
- Tasks are filtered into columns based on `status`.
- Clicking a task "Cycles" it to the next logical status (Todo -> In Progress -> Done -> Todo).
- Column headers automatically count the items they contain.

---

## Objective

Showcase Svelte's lightweight reactivity system and its ability to handle state updates with minimal boilerplate.
