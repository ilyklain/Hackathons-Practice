# Zoom Hackathon Challenge – Room Manager (TS)

## Overview
Manage a dynamic set of meeting participants and their individual audio states efficiently.

## Objective
Use a Map for O(1) access and deletion while providing global operations like 'Mute All'.

## Analysis
- **Time Complexity**: O(1) for join/leave, O(P) for global operations.
- **Concepts**: Map collections, OOP.
