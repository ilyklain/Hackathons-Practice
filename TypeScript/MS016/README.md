# Microsoft Hackathon Challenge – Syntax Tokenizer (TypeScript)

## Overview

This repository contains a TypeScript solution to a Microsoft-style hackathon challenge based on a simplified version of the logic used in VS Code's editor engine. The goal is to transform raw source code text into a stream of identified "Tokens".

---

## Problem Description

Implement a tokenizer that scans an input string and categorizes parts of the text into specific categories: Keywords, Identifiers, and Numbers.

---

## Objective

Demonstrate understanding of string parsing, regular expression matching, and creating type-safe structures in TypeScript.

---

## Complexity Analysis

| Metric | Value |
|------|-------|
| Time Complexity | O(N) where N is the length of the string |
| Space Complexity | O(T) where T is the number of tokens found |
