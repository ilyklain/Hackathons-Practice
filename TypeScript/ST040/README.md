# Stripe Hackathon Challenge – Luhn Validator (TS)

## Overview
Financial systems use the Luhn Algorithm (Mod 10) to quickly check for typing errors in credit card numbers before processing.

## Objective
Implement the mathematical logic to validate card numbers without external libraries.

## Analysis
- **Time Complexity**: O(N) where N is digits length.
- **Concepts**: Parity logic, Numeric aggregation.
