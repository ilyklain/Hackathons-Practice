# Uber Hackathon Challenge – Dynamic Surge Heatmap (Go)

## Overview

This repository contains a Go solution to an Uber-style hackathon challenge focused on geospatial data and real-time logistics. The goal is to identify the most active "Sector" on a map to trigger potential surge pricing.

---

## Problem Description

Convert 2D coordinates into a 10x10 sector grid and count occurrences of ride requests to find the "Hottest Sector".

---

## Objective

Use Go's fast map implementation to aggregate large volumes of spatial data.

---

## Complexity Analysis

| Metric | Value |
|------|-------|
| Time Complexity | O(N) where N is the number of requests |
| Space Complexity | O(G) where G is the number of sectors (max 100) |
