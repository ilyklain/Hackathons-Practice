# DigitalOcean Hackathon Challenge – Tag Manager (Go)

## Overview
Organize cloud infrastructure by transforming discrete metadata tags into a simple, readable summary string.

## Objective
Use the `strings.Join` function effectively while handling null or empty collection cases gracefully.

## Analysis
- **Time Complexity**: O(N) where N is total characters in tags.
- **Concepts**: String concatenation, Edge case handling.
